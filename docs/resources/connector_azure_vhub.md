# alkira_connector_azure_vhub (Resource)

Manage Azure VHUB Connector.

## Routing Options

The `vhub_routing` block is required. You can optionally configure
`route_import_mode` to control what routes Alkira advertises into the
Azure VHUB. Supported modes are `ADVERTISE_DEFAULT_ROUTE` and
`ADVERTISE_CUSTOM_PREFIX`. When using `ADVERTISE_CUSTOM_PREFIX`,
provide `prefix_list_ids`.

## Example Usage

This is a minimal example to create an Azure VHUB connector. An
`alkira_segment` and Azure credential are always required.

```terraform
resource "alkira_connector_azure_vhub" "test1" {
  name           = "test1"
  virtual_hub_id = "/subscriptions/XXXX/resourceGroups/my-rg/providers/Microsoft.Network/virtualHubs/my-vhub"
  credential_id  = alkira_credential_azure_vnet.test1.id
  cxp            = "US-WEST"
  group          = "test"
  segment_id     = alkira_segment.segment1.id
  size           = "SMALL"

  vhub_routing {}
}
```

You can adjust routing options by using `route_import_mode` and
`prefix_list_ids` along with resource `alkira_policy_prefix_list`:

```terraform
resource "alkira_connector_azure_vhub" "test2" {
  name            = "test2"
  virtual_hub_id  = "/subscriptions/XXXX/resourceGroups/my-rg/providers/Microsoft.Network/virtualHubs/my-vhub"
  credential_id   = alkira_credential_azure_vnet.yours.id
  cxp             = "US-WEST"
  group           = "test"
  segment_id      = alkira_segment.segment1.id
  size            = "SMALL"
  scale_group_id  = alkira_group.test.id

  vhub_routing {
    route_import_mode = "ADVERTISE_CUSTOM_PREFIX"
    prefix_list_ids   = [alkira_policy_prefix_list.test.id]
  }
}
```
