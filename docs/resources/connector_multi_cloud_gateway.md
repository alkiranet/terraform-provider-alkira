# alkira_connector_multi_cloud_gateway (Resource)

Manage a Multi-Cloud Gateway connector.

On update, an `instance` block is matched to its stored instance by `name`, not by its
position in the list; a renamed block is treated as a new instance and the old one is removed.

## Example Usage

```terraform
resource "alkira_connector_multi_cloud_gateway" "example" {
  name                   = "example-mcgw-connector"
  size                   = "SMALL"
  description            = "example connector"
  cxp                    = "US-WEST"
  group                  = alkira_group.group1.name
  multi_cloud_gateway_id = alkira_multi_cloud_gateway.example.id
  loopback_prefix        = "10.30.0.0/26"

  segment_options {
    segment_id               = alkira_segment.segment1.id
    advertise_on_prem_routes = true
    disable_internet_exit    = false
  }

  instance {
    name = "instance1"
  }

  instance {
    name = "instance2"
  }
}
```

## Schema

### Required

- `cxp` (String) CXP where the connector is provisioned. Only AWS CXPs support a Multi-Cloud Gateway connector.
- `instance` (Block List, Min: 1) Instances of the connector. On update, a block is matched to its stored instance by `name`; a renamed block is treated as a new instance and the old one is removed. (see [below for nested schema](#nestedblock--instance))
- `loopback_prefix` (String) A free /26 of the gateway's loopback pool, used for tunnel endpoints.
- `multi_cloud_gateway_id` (Number) ID of the `alkira_multi_cloud_gateway` this connector attaches to. The gateway must be `PROVISIONED`.
- `name` (String) Name of the connector.
- `segment_options` (Block List, Min: 1, Max: 1) Segment options for the connector. Exactly one block. (see [below for nested schema](#nestedblock--segment_options))
- `size` (String) Size of each instance: `SMALL`, `MEDIUM`, `LARGE`, `2LARGE`, `5LARGE`, or `10LARGE`.

### Optional

- `billing_tag_ids` (Set of Number) Billing tags associated with the connector. (see resource `alkira_billing_tag`).
- `description` (String) Description of the connector.
- `enabled` (Boolean) Whether the connector is enabled. Default value is `true`.
- `group` (String) Group of the connector.

### Read-Only

- `id` (String) The ID of this resource.
- `provision_state` (String) The provision state of the connector.
